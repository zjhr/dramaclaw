# GoalBuddy Board: ShotRecipe Production Pipeline

## 🎯 目标

建立一个镜头生产配方 (ShotRecipe) 系统，串起角色妆容/表情决策 → 白模预演 → 预检 → 正式渲染 → 续写 → 重拍 → 质量检查，所有结果可迭代、可比较、可溯源。

## 📋 任务列表

- **T001** (Scout): 映射 ShotRecipe 所需的数据模型、现有 API、集成点
- **T002** (Judge): 审阅 Scout 结果，定义 Phase 1 切片
- **T003-T006** (Worker): 依次实现 Phase 1 数据模型 + API + 前端 + 验证
- **T007** (Judge): Phase 1 审计
- **T008** (PM): 最终 e2e 审计
